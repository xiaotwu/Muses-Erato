# P0 macOS → iOS feature and evidence matrix

Status vocabulary: **未实现**, **已有代码未验证**, **自动测试通过**, **模拟器通过**, **真机通过**, **发布准入通过**. A status is the highest P0 evidence for the *target behavior*; tests of old implementation do not promote a row for the public IFrame path. `p0-verification.md` records commands and devices. All rows have **no real-device or release-admission evidence** at P0.

## Acceptance evidence still required

For each row, P1–P6 should add a dated record with build SHA, iPhone/iPad model and OS, account/video fixture, network, observed result and failure screenshots/logs. Simulator success is recorded separately from physical playback, audio routing, interruption, memory, signing and App Review acceptance. A public release cannot inherit macOS's authorization assumptions.
